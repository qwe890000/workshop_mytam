**On this page**, you will find the worklog documenting the internship journey at AWS Vietnam. The program lasted **12 weeks**, from 18/04/2026 to 12/07/2026. Below are the weekly summaries:

**Week 1 (18/04 – 24/04):** [Form team, set up internship group, learn AWS on draw.io and attend workshop](1.1-week1/)

**Week 2 (25/04 – 01/05):** [Register AWS account and complete Module 01: Lab01 – Lab07](1.2-week2/)

**Week 3 (02/05 – 08/05):** [Complete Module 01-Lab09 (AWS Support) and Module 02-01, 02-02: VPC, Multi-VPC](1.3-week3/)

**Week 4 (09/05 – 15/05):** [Complete Module 02-03, 02-Lab03-01 and start working at the company office](1.4-week4/)

**Week 5 (16/05 – 22/05):** [Learn Security Group, ACL, VPC Resource Map; create VPC, Subnet, IGW, Route Table, Security Group, EC2 Instance](1.5-week5/)

**Week 6 (23/05 – 29/05):** [Cost management with AWS Budgets, access management with AWS IAM](1.6-week6/)

**Week 7 (30/05 – 05/06):** [Getting Started on EC2, granting access via IAM Role, Cloud IDE and Hosting Static Website on S3](1.7-week7/)

**Week 8 (06/06 – 12/06):** [Database with Amazon RDS, Lightsail, Auto Scaling on EC2 and CloudWatch monitoring system](1.8-week8/)

**Week 9 (13/06 – 19/06):** [Set up Hybrid DNS with Route53, AWS CLI on EC2 and participate in HA Web Application Workshop](1.9-week9/)

**Week 10 (20/06 – 26/06):** [Complete Numerology project, research Lenormand materials and design DB with Amazon DynamoDB](1.10-week10/)

**Week 11 (27/06 – 03/07):** [Complete Internship Report, Progress Tracking Form and Internship Evaluation Form](1.11-week11/)

**Week 12 (04/07 – 12/07):** [Submit all forms to the company, submit personal Workshop and wrap up the internship](1.12-week12/)
